# 🌭 Food for Thought: Working with files

Although the topics covered in this chapter only scratch the surface, they lay the groundwork for a wide range of tasks related to files.

It is also at this point that things start to diverge. The tools described in this chapter are well known and widely available across different Linux distributions. However, users will eventually develop tools that are better suited to their file management tasks, as well as tools for analysing file contents. 

As discussed in [Chapter 4](04-executables.md), adding new tools to your Linux system is fairly simple. Moreover, new tools are more readily available than ever before.

Therefore, it is sufficient to mention this here before moving on to more generic topics applicable to all Linux operating systems. The next chapter will explain [processes](07-processes.md).
