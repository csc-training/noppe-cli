# Batch

Files are often handled in 'batches', which means that rather than dealing with one file at a time, you may need or want to deal with several at once.

## Globbing

Let's create some material to work with and simulate a data file for each day of 2026. Create an empty directory called `data26` and change your location to it.

::: service
Copy and paste the command from here: `touch data_{01..31}{01..12}26`. The command contains two _brace expansions_ to create multiple files in one command.
:::

Use the `ls` command to verify that the files have been created.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ mkdir data26
{{USERNAME}}@{{HOSTNAME}}:~$ cd data26
{{USERNAME}}@{{HOSTNAME}}:~/data26$ touch data_{01..31}{01..12}26
{{USERNAME}}@{{HOSTNAME}}:~/data26$ ls█
:::

Imagine that you are having trouble accessing a data file on the 15<sup>th</sup> of a month, but you don't know which month.

Rather than running the `ls -l data_150126` command for every month, you can list all the months by replacing the month with two question marks `??`. One question mark represents any single character; two question marks, any two characters; and so forth.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~/data26$ ls -l data_15??26
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150126
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150226
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150326
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150426
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150526
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150626
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150726
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150826
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_150926
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_151026
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_151126
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 0 Dec  6 08:24 data_151226
{{USERNAME}}@{{HOSTNAME}}:~/data26$ █
:::

The question mark is useful because it matches one character exactly. However, sometimes you may want the match be zero, one or multiple characters or strings. In this case, you can use the `*` character.

For example, to list all files from December, you can enter the following command: `ls -l *1226`. Note that you don't even have to include the beginning of the filename in your command.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ ls -l *1226█
:::

We can combine all the globbing techniques into one. The following command:

`ls -l data_?[0,2,4,6,8]*`

uses a question mark to represent a single character, brace expansion, and an asterisk to represent multiple characters. Can you tell what kind of files the command lists? Try it out yourself!

::: question
There are data files from days that does not exist (e.g. 31.4.2026). Can you find and delete them?
:::

Let's look at another example using the `grep` command instead of the `ls` command. This time, we'll perform a regular expression search on a group of md files.

::: note
Globbing and brace expansion are different from regular expressions.
:::

The command `grep "^# " noppe-cli/basics-of-linux/*.md` executed from user's home directory, will target the regular expression `^# ` using grep into all files ending with `.md` in `basics-of-linux` directory.

As a result, it will print the name of the file and the matching text row (i.e. the row that begins with a hashtag and a space).

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ grep "^# " noppe-cli/basics-of-linux/*.md
noppe-cli/basics-of-linux/00-toc.md:# Basics of Linux
noppe-cli/basics-of-linux/01-introduction.md:# Introduction
noppe-cli/basics-of-linux/01.1-cli.md:# CLI
noppe-cli/basics-of-linux/01.2-food-for-thought.md:# 🌭 Food for Thought: Introduction
noppe-cli/basics-of-linux/02-navigation.md:# Navigation
noppe-cli/basics-of-linux/02.1-food-for-thought.md:# 🌭 Food for Thought: Navigation
noppe-cli/basics-of-linux/03-files-and-directories.md:# Files and directories
noppe-cli/basics-of-linux/03.1-file-properties.md:# File properties
noppe-cli/basics-of-linux/03.2-links.md:# Links
noppe-cli/basics-of-linux/03.3-food-for-thought.md:# 🌭 Food for Thought: Files and directories
...
{{USERNAME}}@{{HOSTNAME}}:~$ █
:::

In practice, the level one headers (i.e. chapter titles) are printed out.

## Archives

You may have come across files with `.tar.gz` or `.tar.bz` extensions when using Linux.

These are compressed files containing multiple items. As well as compression, you can benefit from features such as preserving the file structure, permissions, and timestamps.

### Create

In the Globbing chapter above, we created a directory called `data26`. Let's create couple of tarballs out of that directory: 

`tar cf backup-data26.tar data26/`

and then create another file with the command:

`tar cfz backup-data26.tar.gz data26/`

Check out the created files first with the `ls -l backup*` command and then with the `file backup-data26.tar` and `file backup-data26.tar.gz` commands.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ tar cf backup-data26.tar data26/
{{USERNAME}}@{{HOSTNAME}}:~$ tar cfz backup-data26.tar.gz data26/
{{USERNAME}}@{{HOSTNAME}}:~$ ls -l backup*
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}} 194560 Dec  6 09:24 backup-data26.tar
-rw-rw-r-- 1 {{USERNAME}} {{USERNAME}}   3299 Dec  6 09:24 backup-data26.tar.gz
{{USERNAME}}@{{HOSTNAME}}:~$ file backup-data26.tar
backup-data26.tar: POSIX tar archive (GNU)
{{USERNAME}}@{{HOSTNAME}}:~$ file backup-data26.tar.gz
backup-data26.tar.gz: gzip compressed data, from Unix, original size modulo 2^32 194560
{{USERNAME}}@{{HOSTNAME}}:~$ █
:::

The `tar` command dates back to the era of tape archives and has a long history. The `c` argument is used to create a file specified after the `f` argument. The optional `z` argument compresses the resulting tarball.

::: note
You can use `j` instead of `z` to select bzip2 (`.bz`) compression rather than gzip (`.gz`) compression.
:::

### Access

The contents of a tarball can be listed using the `tar tf backup-data26.tar.gz` command, and extract its contents using the `tar xf backup-data26.tar.gz` command.

Use the `rm -fr` command to delete the `data26` directory, and then restore the content from the `backup-data26.tar.gz` file.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ rm -fr data26
{{USERNAME}}@{{HOSTNAME}}:~$ tar xf backup-data26.tar.gz
{{USERNAME}}@{{HOSTNAME}}:~$ █
:::

::: tip
Tar can automatically recognise the compression method used to extract files from an archive.
:::

You can use the `ls` command after both these commands to verify that the data has been deleted and recovered.

## Finding files

There are various ways of finding files in the Linux system, such as the `whereis` command that we have already used. One of the most powerful one is presented here: `find`.

Type the command `find ~ -name "basics-of-linux.png" -exec catimg {} \;` and press `Enter ↵`.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ find ~ -name "basics-of-linux.png" -exec catimg {} \;█
:::

This can be interpreted as: `find` files in the `~` (home directory) with the `-name` `basics-of-linux.png` and `-exec`ute the `catimg` command for each matching file.

The `{} \;` part acts as a placeholder for the name of each found file.

As said, the `find` command is a very powerful tool. This was just one simple example of how it can be used. The `find` command's [manual page](https://man7.org/linux/man-pages/man1/find.1.html) is well worth a read.
