# Food for Thought: Redirections

| Syntax          | Description                                     |
|-----------------|-------------------------------------------------|
| `> file`        | `stdout` to `file` (overwrite)                  |
| `>> file`       | `stdout` to `file` (append)                     |
| `2> file`       | `stderr` to `file` (overwrite)                  |
| `2>> file`      | `stderr` to `file` (append)                     |
| `2>&1`          | `stderr` to wherever `stdout` currently points  |
| `< file`        | `stdin` from `file`                             |
| `cmd1 \| cmd2`  | Pipe: `stdout` of `cmd1` becomes `stdin` of `cmd2` |
| `cmd1 2>&1 \| cmd2` | Pipe both `stdout` and `stderr` of `cmd1` to `cmd2` |



| POSIX                 | Bash shorthand    |
|-----------------------|-------------------|
| `> file 2>&1`         | `&> file`         |
| `>> file 2>&1`        | `&>> file`        |
| `cmd1 2>&1 \| cmd2`   | `cmd1 \|& cmd2`   |
