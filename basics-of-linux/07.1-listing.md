# Listing processes

You have already used the `pstree` and `ps` commands to list the currently running processes.

Here are a couple more examples of these commands:

Use the command `echo $$` to check the process ID of your current bash process. Then use `pstree -s [PID]`, where `[PID]` is the output of the previous command, to view the process tree related only to your Bash PID.

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ echo $$
121
{{USERNAME}}@{{HOSTNAME}}:~$ pstree -s 121
tini───caddy───ttyd───login───bash───pstree
{{USERNAME}}@{{HOSTNAME}}:~$ █
:::

Then, run the following command to view all running processes in a different way: `ps -eo pid,ppid,%cpu,%mem,args --sort=+ppid`.

With these arguments, the `ps` command lists certain columns for each running process and sorts the output in ascending order by parent process ID (PPID).

::: terminal
{{USERNAME}}@{{HOSTNAME}}:~$ ps -eo pid,ppid,%cpu,%mem,args --sort=+ppid
    PID    PPID %CPU %MEM COMMAND
      1       0  0.0  0.0 /usr/bin/tini -- /start
      7       1  0.0  0.5 caddy run --config /etc/caddy/Caddyfile
     57       1  0.0  0.0 /usr/sbin/munged
     78       1  0.0  0.0 slurmd
     81       1  0.1  0.1 slurmctld
     13       7  0.0  0.0 ttyd -W -p 7681 login
    110      13  0.0  0.0 login
     82      81  0.0  0.0 : slurmscriptd
    121     110  0.0  0.0 -bash
    141     121  0.0  0.0 ps -eo pid,ppid,%cpu,%mem,args --sort=+ppid
{{USERNAME}}@{{HOSTNAME}}:~$ █
:::

::: guidance
Please refer to the manual pages for these commands to see the various output options available.
:::

## Dynamic view

All right, we have used tools to take a snapshot of the processes that are currently running. But what if we want to monitor them continuously?

Let's introduce a new command: `watch`. This can be used with any other command. Here, we will combine it with the `ps` command: `watch ps -eo pid,ppid,%cpu,%mem,comm --sort=-%cpu`.

::: terminal
Every 2.0s: ps -eo pid,ppid,%cpu,%...  {{HOSTNAME}}: Sun Dec 06 07:38:53 2026

    PID    PPID %CPU %MEM COMMAND
     81       1  0.1  0.1 slurmctld
    143     121  0.0  0.0 watch
      7       1  0.0  0.5 caddy
     13       7  0.0  0.0 ttyd
    121     110  0.0  0.0 bash
    110      13  0.0  0.0 login
      1       0  0.0  0.0 tini
     57       1  0.0  0.0 munged
     78       1  0.0  0.0 slurmd
     82      81  0.0  0.0 slurmscriptd
    151     143  0.0  0.0 sh
    152     151  0.0  0.0 ps
:::

By default, `watch` runs the specified command every two seconds and refreshes the view with the command's output. Here, we used `ps` to print out the running processes and sort the list in descending order by CPU usage.

You can exit the `watch` command by pressing `Ctrl+C`.

:::quiz q-linux-13
:::
