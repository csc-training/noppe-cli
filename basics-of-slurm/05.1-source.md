# 5.1 Source code

The complete source for the Hello World example. See [Hello World](05-hello-world.md) for the walkthrough.

## C++  (`src/hello_world/cpp/`)

**main.cpp**

```cpp
#include<iostream>

int main(){
	std::cout << "Hello World!" << std::endl;
}//main
```

**Makefile**

```makefile
CC = g++
BINNAME = main.exe

$(BINNAME): main.cpp
	$(CC) -o $@ $<

clean:
	rm -f *.exe *.txt
```

**slurmscript.sh**

```bash
#!/bin/bash
#SBATCH --job-name=hello_world_cpp
#SBATCH --output="out.txt"
#SBATCH --time=00:00:30

make
./main.exe
```
