# 6.1 Source code

The complete source for the time limit example. See [Time limit](06-time-lim.md) for the walkthrough.

## C++  (`src/limits/time/`)

**main.cpp**

```cpp
#include<iostream>
#include<unistd.h>

int main(){
	std::cout << "Hello World!" << std::endl;
	int t = 120;
	std::cout << "Sleeping for " << t << " seconds" << std::endl;
	sleep(t);
	std::cout << "Finished sleeping" << std::endl;
}//main
```

**Makefile**

```makefile
CC = g++
BINNAME = main.exe

$(BINNAME): main.cpp
	$(CC) -o $@ $<

clean:
	rm -f *.exe *.txt
```

**slurmscript.sh**

```bash
#!/bin/bash
#SBATCH --job-name=time_limit
#SBATCH --output="out.txt"
#SBATCH --error="err.txt"
#SBATCH --time=00:01:00

make
./main.exe
```
